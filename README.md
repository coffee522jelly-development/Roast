# Roast - 自家製音楽管理アプリ

Roast（ロースト）は、じっくりと音楽ファイルと向き合いたい人のための、ミニマルで洗練されたMP3管理アプリです。Tauri v2、React、そして shadcn/ui を使用して構築されています。

## コンセプト
「自家製」の温かみと、最新のデスクトップ技術を融合。散らかった音楽ファイルをアーティストごとに丁寧に仕分けし、タグを整える。そして、こだわりのプレイヤーで音を深く聴き込む。そんな時間を楽しむためのツールを目指しています。

## 主な機能

- **自動フォルダ振り分け (Organize)**
  - ファイル名パターン（例：「アーティスト名 - 曲名」）からアーティスト名を自動抽出し、専用フォルダを作成して移動します。
  - 移動と同時に、ID3タグ（アーティスト・タイトル）も自動更新し、ファイル名をクリーンに保ちます。

- **高機能プレイヤー**
  - **波形表示 (Waveform)**: 音声をデコードし、視覚的に美しい波形を表示。
  - **A-B リピート**: 特定の区間を繰り返し再生。フレーズの確認や耳コピに最適。
  - **DJ フィルター**: Web Audio API を使用した Low Pass (LPF) および High Pass (HPF) フィルターを搭載。特定の音域にフォーカスして聴き込むことができます。
  - **集中モード (Focus Mode)**: ウィンドウをコンパクトにし、アルバムアートを中央に配置。音楽だけに没頭できるモードです。

- **ライブラリ管理**
  - **グリッドビュー**: アルバムアートを敷き詰めた没入感のあるブラウジング。
  - **詳細サイドバー**: アルバムアートワーク、ビットレート、サンプリングレートなどの詳細なファイル情報を表示。
  - **メタデータ編集**: タイトル、アーティスト、アルバム、リリース年を直接編集可能。

- **カスタマイズ**
  - **テーマカラー**: 7つのアクセントカラー（Zinc, Rose, Blue, Violet など）。
  - **背景モード**: Light, Dark に加え、Espresso, Sepia などの目に優しい背景を選択可能。

## 使い方

1. アプリを起動し、設定（歯車アイコン）から音楽フォルダを選択します。
2. リストまたはグリッドから曲を選択し、ダブルクリックで再生を開始します。
3. プレイヤーバーの「A」「B」ボタンでループ区間を設定できます。
4. 「Filter System」を ACTIVE にすると、LPF/HPF スライダーで音質をリアルタイムに調整できます。
5. 右上のボタンで「集中モード」に切り替え、音楽との対話を楽しめます。

*※外部プレイヤーでの再生機能は削除されました。Roast内部での再生に特化しています。*

## 技術スタック
- **Frontend**: React 19, TypeScript, Tailwind CSS, shadcn/ui (Radix UI)
- **Backend**: Rust, Tauri v2
- **Crates**: id3, mp3-metadata, mp3-duration, walkdir, serde

## 開発者向け
このプロジェクトは Tauri v2 を使用しています。

```bash
# 依存関係のインストール
npm install

# 開発モードで起動
npm run tauri dev
```
